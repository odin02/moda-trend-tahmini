# moda-trend-tahmini
# Tüketici Tercihleri ile Ar-Ge Odaklı Moda Trend Tahmini

## Proje Hakkında
Bu proje; tüketici tercihleri, satın alma alışkanlıkları ve pazar verilerini analiz ederek Ar-Ge odaklı moda trendlerini tahmin etmeyi ve gelecekteki tasarım/üretim kararlarına veri odaklı içgörüler sunmayı amaçlamaktadır.

## Kullanılan Teknolojiler
* Python
* Pandas, NumPy (Veri İşleme ve Analiz)
* Jupyter Notebook
